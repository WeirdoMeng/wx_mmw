# 托管机构小程序

一个原生微信小程序。教师处理自己负责的学生和作业反馈，发布机构托管动态。家长可以绑定同机构的多个孩子，在「我的孩子」中切换，加入多家机构时可在「我的」切换机构。

## 本地和真机联调

1. 在同级目录 `tuoguan_back` 运行 `npm run dev` 可以使用独立数据和测试身份进行本机联调。真实微信环境的配置见 [独立后端部署说明](../tuoguan_back/README.md)。
2. 用微信开发者工具打开本目录，保持项目 AppID 与后端 `WX_APPID` 一致。
3. 开发者工具的开发版可在 `miniprogram/config.js` 留空 `apiOrigin`，自动访问 `http://127.0.0.1:3000`。联调本机服务时在开发者工具按需关闭域名校验。上传体验版和正式版前，填写后端 HTTPS 根域名，并在微信公众平台配置同一域名的 `request`、`uploadFile`、`downloadFile`。 [微信网络文档](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)
4. 在与小程序共用后端数据的网页后台打开机构的「登记码」。配置了微信发码时，可直接用微信「扫一扫」打开教师或家长登记页。小程序内的「扫描机构二维码」也支持相机和相册。教师填写资料并经机构审核启用后，可用同一微信账号进入教师端。家长可扫描家长码，或从已绑定机构的「添加孩子」登记。

未配置公网域名时，可选择「本地真机联调」编译模式，在同一 Wi-Fi 下以真实微信身份使用开发版。未绑定的微信号进入扫码登记页。配置命令和连接验证见 [同一 Wi-Fi 的真机调试](../tuoguan_back/README.md)。

## 验收场景

- 使用固定教师二维码登记与审核，验证启用后再次进入小程序可直接打开教师端，停用后退出机构。
- 在网页后台的教师列表打开「权限设置」，为一名已启用的教师开启「登记审核」。该教师可从小程序「我的 → 审核」处理本机构教师和家长的登记申请。撤回权限后，审核入口隐藏，当前打开的审核页也无法继续处理。
- 家长扫码登记孩子。后台审核通过即可绑定，家长重新打开小程序可查看已绑定的孩子。多个家长可以关联同一份学生档案。家长已在机构绑定一个孩子时，可从「添加孩子」登记同机构的兄弟姐妹。
- 切换同机构的两个孩子，提交作业时确认显示的姓名。分别查看作业、反馈与联系信息，验证记录按孩子隔离，且重新打开时保留已选孩子。
- 教师在「我的学生 → 家长信息」中点击联系电话旁的电话图标，核对手机拨号界面带入的是该行号码。
- 家长选择未来日期上传作业，老师选择同一学生和日期查看并修改整体反馈。教师分享已保存的反馈时，聊天卡片使用实际学生、日期、完成状态、反馈摘要和首张可用照片。另一个家长账号通过分享入口应无法读取非归属学生记录。验证相册选图、连续拍摄和单次提交最多 20 张照片。
- 两端日历在家长已提交作业时标蓝，教师提交反馈后标绿。当天没有任何提交时留空，周历和月历底部均有图例。
- 老师发布餐食和日常，家长从动态列表打开详情。将详情分享至微信聊天或朋友圈时，卡片使用实际标题、描述摘要和首张可用照片。朋友圈单页通过底部「前往小程序」进入完整详情，详情需登录并通过机构权限校验。老师可在「托管动态 → 每周菜谱」按天编辑整周荤菜、素菜、汤菜并附最多 20 张图片。家长和教师可切周，通过「查看与分享」分享有内容的一周。
- 用两个机构分别登记学生和发布动态。加入两家机构的账号可切换，其他账号仅可访问自己的机构。

界面线性图标使用 Lucide，见 [许可证](miniprogram/images/ui/LICENSE)。

平台管理员使用 [托管管理后台](../tuoguan_web/README.md) 维护机构、老师、学生资料和学生归属。
